## 🛠️ Professional Profile
Un profil hibrid ce integrează experiența operativă în asamblarea industrială de înaltă precizie (**Flex**) cu expertiza lingvistică în **Limbi Moderne Aplicate (LMA)**. Proiectul este fundamentat pe studiul sistemelor critice de zbor și al protocoalelor de siguranță aeronautică, fiind inspirat de metodologiile de analiză din **Air Crash Investigation**.

## 🚀 Key Technical Projects

### 1. Multi-Language Cockpit Simulator (GPWS Logic)
* **Core Tech:** JavaScript Engine | Web Speech API (TTS Integration)
* **Specialization:** Implementarea unui sistem de alertă **GPWS (Ground Proximity Warning System)**.
* **Features:**
    * Interfață trilingvă nativă: **English / Français / Italiano**.
    * Simulare alerte auditive de urgență ("Pull Up", "Terrain").
    * Codificare logică pentru scenarii de zbor critice.

### 2. Aero-Maintenance & Diagnostic Tool
* **Core Tech:** HTML5 Canvas Rendering | Web Audio API (Signal Processing)
* **Specialization:** Diagnoza sistemelor de control al zborului (Eleroane).
* **Technical Specs:**
    * **Acoustic Simulation:** Generarea frecvenței de operare hidraulică la **2000Hz**.
    * **X-Ray Visualization:** Sistem de inspectare a integrității structurale prin straturi de randare.
    * **UX:** Interfață optimizată pentru diagnosticare rapidă în flux de mentenanță.

### 3. Technical Knowledge Engine (Mobile Optimized)
* **Status:** *Under Development*
* **Focus:** Modul de evaluare a competențelor tehnice aeronautice, adaptat pentru utilizare cross-platform.
